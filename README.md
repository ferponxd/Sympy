# Sympy
Este repositorio contiene modelos
de simulación de eventos discretos
utilizando SimPy.

Se modela un sistema similar
a una caseta de cobro como
Chamapa-Lechería.

Modelos incluidos:

1. Modelo base
   Una fila y una caseta.

2. Modelo intermedio
   Una fila y múltiples casetas.

3. Modelo complejo
   Dos casetas con tiempos
   de servicio variables.
